Projeto desenvolvido em Python para simular o monitoramento de um reservatório de água.

[![Static Badge](https://img.shields.io/badge/Descri%C3%A7%C3%A3o%20-%20green)](https://img.shields.io/badge/%F0%9F%93%9D-Descri%C3%A7%C3%A3o-green)

O sistema exibe mensagens de alerta no terminal de acordo com o nível de água informado pelo usuário. Cada situação é representada por uma cor diferente utilizando a biblioteca Colorama.
Necessário instalar a biblioteca Colorama:
pip install colorama

![Static Badge](https://img.shields.io/badge/%F0%9F%9B%A0%EF%B8%8F%20-%20Tecnologias%20Utilizadas%20-%20Black)

Python 3
Colorama

[![Static Badge](https://img.shields.io/badge/Funcionalidades%20%20-%20%20Yellow)](https://img.shields.io/badge/%E2%9A%99%EF%B8%8F%20Funcionalidades-pink)

Identificação de 5 níveis do reservatório;
Exibição de mensagens coloridas;
Utilização de lista para armazenar os níveis;
Validação de nível inválido;
Restauração das configurações padrão do terminal.


![Static Badge](https://img.shields.io/badge/%F0%9F%93%8A%20N%C3%ADveis%20Monitorados-grey)

Nível	Situação

1	Muito baixo (Crítico)

2	Baixo

3	Médio

4	Alto

5	Muito alto (Alerta)

![Static Badge](https://img.shields.io/badge/Como%20executar-green)


O sistema vai solicitar o nível da água ou do reservatório é só digitar um numero de 1 a 5 para visualizar a situação correspondente.
